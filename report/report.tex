\dropcap{M}{\bf odern chess engines use standard search techniques} like alpha-beta pruning and deep learning to evaluate positions and look for an optimal playing strategy. However, they do not consider the network structure of the game's state space. This means the quality of the solution depends entirely on evaluating individual positions.

In this work, we propose a network analysis approach to guide the search. Instead of evaluating a position in isolation, we assess the broader community of states it belongs to. The intuition behind this is that a seemingly good position might be fragile if it is surrounded by losing states. We map the local state space by exploring all legal moves from a starting position up to a limited depth using Depth First Search (DFS). By focusing on endgames with up to seven pieces, we can assign an exact Win, Draw or Loss (WDL) state to each node using Syzygy tablebases. We then extract distinct communities using the Leiden algorithm. To evaluate these groups, we introduce a new metric that rewards winning and drawing proportions while punishing losing states. By treating communities as nodes in a new graph, we model optimal and robust paths using Dijkstra's algorithm. This method naturally guides the search through safe regions of the state space while penalizing paths that pass through risky or bad communities.

Building a full network takes a lot of computing power. Because of this, we also test if sampling the network keeps the same communities. We use Normalized Mutual Information (NMI) to evaluate how well two different sampling methods (random node selection and probabilistic DFS) preserve the original community structure. By comparing these techniques across different sampling rates, we investigate the trade-offs between reducing the network size and maintaining structural accuracy.

\section*{Related work}

Network analysis has so far been applied to the domain of chess positions either as a means of encoding an individual position on the board \cite{chess} with the goal of predicting the outcome of the game, or as an analysis tool, for instance, of the openings with respect to the skill level of the players \cite{chess3}. In addition, clustering methods were used on the openings to infer the result or other properties of the game \cite{chess2}.

\section*{Results}
To evaluate our approach, we generated a state space network from the starting position with FEN: \emph{3r4/2k5/5P2/7K/8/8/8/8 b - - 0 1}. We bounded the generation to two different limits: a network bounded to a maximum depth of 5 and a larger network bounded to a depth of 7 to verify scalability.

To identify favorable regions, we ranked communities by individual quality ($Q_{0.5}$) and calculated the cumulative path cost ($C_{0.5}$) from the community with starting state using Dijkstra's algorithm.

To test structural robustness under computational constraints, we averaged the Normalized Mutual Information (NMI) over 25 repetitions for both random node and probabilistic DFS sampling across varying probabilities ($p$).

\subsection*{Mathematical Modeling of Chess Positions}

We treat chess positions as nodes in a graph, and transitions between positions as directed edges.
In a directed chess position graph $D$, there exists a directed edge between two positions $v, u \in V(D)$ if and only if there positions are one valid chess move apart.
This gives us a discrete distance between all chess moves, where reachable neighboring chess positions are exactly one distance apart.
