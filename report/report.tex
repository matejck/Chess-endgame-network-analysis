\begin{abstract}
Modern chess engines evaluate positions in isolation, ignoring the broader network structure of the game. Consequently, seemingly strong positions can be fragile if surrounded by losing states. We propose a novel heuristic that evaluates entire communities of game states rather than single nodes. Focusing on 7-piece endgames, we mapped the state space using limited-depth DFS and assigned Win/Draw/Loss states using Syzygy tablebases. We extracted communities using the Leiden algorithm and applied a custom metric that penalizes losing states. By condensing these communities into a macro-network, we used Dijkstra's algorithm to calculate robust, safe paths. To reduce high computational costs, we tested sampling methods. Results show probabilistic DFS sampling is highly practical, maintaining strong community structure (NMI of 0.898 at a 0.8 probability for depth 7). This scalable method effectively guides engines through structurally safe regions of the game.
\end{abstract}

\dropcap{M}{\bf odern chess engines use standard search techniques} such as Monte Carlo Thee Search and alpha-beta pruning for search and deep learning to evaluate positions and look for an optimal playing strategy. However, they do not consider the network structure of the game's state space. This means the quality of the solution depends entirely on evaluating individual positions.

In this work, we propose a network analysis approach to guide the search. Instead of evaluating a position in isolation, we assess the broader community of states it belongs to. The intuition behind this is that a seemingly good position might be fragile if it is surrounded by losing states. We map the local state space by exploring all legal moves from a starting position up to a limited depth using Depth First Search (DFS). By focusing on endgames with up to seven pieces, we can assign an exact Win, Draw or Loss (WDL) state to each node using Syzygy tablebases. We then extract distinct communities using the Leiden algorithm. To evaluate these groups, we introduce a new metric that rewards winning and drawing proportions while punishing losing states. By treating communities as nodes in a new graph, we model optimal and robust paths using Dijkstra's algorithm. This method naturally guides the search through safe regions of the state space while penalizing paths that pass through risky or bad communities.

Building a full network takes a lot of computing power. Because of this, we also test whether the network sampling keeps the same communities. We use Normalized Mutual Information (NMI) to evaluate how well two different sampling methods (random node selection and probabilistic DFS) preserve the original community structure. By comparing these techniques across different sampling rates, we investigate the trade-offs between reducing the network size and maintaining structural accuracy.

\section*{Related work}

Network analysis has so far been applied to the domain of chess positions either as a means of encoding an individual position on the board \cite{chess} with the goal of predicting the outcome of the game, or as an analysis tool, for instance, of the openings with respect to the skill level of the players \cite{chess3}. In addition, clustering methods were used on the openings to infer the result or other properties of the game \cite{chess2}. 

\section*{Results}
To evaluate our approach, we generated a state space network from the starting position with FEN: \emph{3r4/2k5/5P2/7K/8/8/8/8 b - - 0 1}. We bounded the generation to maximum depths of 5 and 7 to evaluate scalability and visualized the resulting networks using the ForceAtlas2 \cite{atlas} graph layout algorithm, as shown in Figures \ref{fig.network1} and \ref{fig.network2}.

To identify favorable regions, we ranked communities by individual quality ($\mathcal{Q}_{0.5}$) and calculated the cumulative path cost ($\mathcal{C}_{0.5}$) from the community with starting state using Dijkstra's algorithm.

To test structural robustness under computational constraints, we averaged the Normalized Mutual Information (NMI) over 25 repetitions for both random node and probabilistic DFS sampling across varying probabilities ($p$).

\section*{Discussion}
The visualizations made with the ForceAtlas2 algorithm (networks \ref{fig.network1.wdl} and \ref{fig.network2.wdl}) reveal the structure inherent in the chess state space. Because the layout pulls connected nodes together and pushes disconnected ones apart, the network forms numerous dense regions. These densely connected regions indicate that the network has high modularity.

Leiden algorithm successfully detects these densely connected regions as communities, as shown in \ref{fig.network1.leiden} and \ref{fig.network2.leiden}. If multiple distinct densely connected regions share many connections between them, the algorithm detects them as one community. 

Detected communities are then converted into a community network (networks \ref{fig.network1.leiden} and \ref{fig.network2.leiden}), such that communities are condensed into single nodes and multiple connections are simplified into single edges. By shrinking thousands of individual positions into a few main regions, we create a simple map of the game. Simplifying the connections lets us see the general flow between these areas. When we visualize community network, its overall shape closely represents the form of the original graph.

Table \ref{table.network1.scores} represents top 5 communities in the network with limited depth of 5 using two different scoring methods. The first column ranks the communities based on their individual score, denoted as $\mathcal{Q}_{0.5}^\text{norm}$. Community 14 has the highest $\mathcal{Q}_{0.5}^\text{norm}$ of 0.938. The second column ranks the safest reachable communities based on cumulative path cost, denoted as $\mathcal{C}_{0.5}$. This cost is calculated using Dijkstra's algorithm. Community 11 has the $\mathcal{C}_{0.5}$ of 0.000, because it contains the starting position of the game. That is why Community 1 has the best $\mathcal{C}_{0.5}$ of 0.186. Because the path cost accumulates with every step, the lowest score is obtained in one of the communities that is neighbor of the one with starting position. 

%Building a full network takes a lot of computing power. Because of this, we tested if sampling the network keeps the same communities. 
Table \ref{table.network1.NMI} and Table \ref{table.network2.NMI} show the results for Node Sampling NMI and DFS Sampling NMI.

In both cases, as the probability parameter $p$ is lowered, the NMI for node sampling drops slower than the NMI for DFS sampling. However, node sampling cannot be utilized when creating the network, meaning the full network must already exist for this method to work. NMI for DFS sampling drops faster as $p$ decreases, but it seems that for the network with depth 7, it dropped a bit less compared to the depth 5 network. This means we can use probabilistic DFS sampling to save time during generation while still keeping a reasonably accurate map of communities.


\section*{Methods}
For a given state space network $G$, let $\mathcal{W}$ be set of all winning positions, $\mathcal{D}$ set of all drawing positions and $\mathcal{L}$ set of all losing positions in $G$. We define
\begin{align*}
    W(c_i) = \frac{|c_i \cap \mathcal{W}|}{|c_i|}, \quad  D(c_i) = \frac{|c_i \cap \mathcal{D}|}{|c_i|}, \quad L(c_i) = \frac{|c_i \cap \mathcal{L}|}{|c_i|}.
\end{align*}

To evaluate the quality of the communities found by the Leiden algorithm, we designed a custom metric based on the proportions of winning, drawing, and losing states. For a given community $c_i$, we define the initial quality function as:
\begin{align*}
    \mathcal{Q}_\alpha(c_i) = 1 + \alpha  W(c_i) - (1 - \alpha) L(c_i).
\end{align*}
The parameter $\alpha$ allows us to balance how much we reward winning states versus how heavily we punish losing states. We then normalize this function so that the best possible community scores a 1 and the worst possible community scores a 0:
\begin{align}
    \mathcal{Q}_\alpha^{\text{norm}}(c_i) = W(c_i) + (1 - \alpha)D(c_i).
    \label{Q_norm}
\end{align}
This normalized score gives us individual evaluation for every community.

However, simply picking the highest scoring community is not enough, because reaching it might require passing through highly dangerous ones. To model safe navigation, we convert these quality scores into edge weights for pathfinding. The weight of a directed edge $(u, v)$ from one community to another is defined as:
\begin{align*}
    w(u, v) = -\ln(\mathcal{Q}_\alpha^{\text{norm}}(v)).
\end{align*}
 If a target community $v$ is perfect (a score of 1), its cost becomes zero. As the community's quality gets worse and closer to zero, the penalty grows exponentially. This guarantees that transitioning into bad communities is heavily punished.

 Finally, we calculate the safest route to any target community using the cumulative path cost:
\begin{align}
    \mathcal{C}_\alpha(c_i) &= \min_{P \in \mathcal{P}(c_s, c_i)} \sum_{(u, v) \in P} w(u, v), \nonumber\\
    &= \min_{P \in \mathcal{P}(c_s, c_i)} \sum_{(u, v) \in P} \left[ -\ln(\mathcal{Q}_\alpha^{\text{norm}}(v)) \right],
    \label{C}
\end{align}
where $c_s$ is the starting community (the community that contains the starting position), $\mathcal{P}(c_s, c_i)$ is the set of all valid paths from the starting community to the target community $c_i$ and $w(u, v)$ is the weight of the edge $(u, v) \in G$.

By applying Dijkstra's algorithm to \eqref{C}, we find the path that minimizes the total accumulated edge weights. This guides the search through the most robust and secure regions of the game while avoiding bad communities.

\subsection*{Mathematical Modeling of Chess Positions}

We treat chess positions as nodes in a graph, and transitions between positions as directed edges.
In a directed chess position graph $D$, there exists a directed edge between two positions $v, u \in V(D)$ if and only if there positions are one valid chess move apart.
This gives us a discrete distance between all chess moves, where reachable neighboring chess positions are exactly one distance apart.
